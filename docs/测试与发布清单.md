# 测试与发布清单

## 自动检查

- [ ] `gradlew testReleaseUnitTest` 通过
- [ ] `gradlew lintRelease` 无 Error
- [ ] `gradlew assembleRelease` 通过
- [ ] APK 包名为 `com.fjxm.print`
- [ ] `minSdk=28`、`targetSdk=36`
- [ ] APK 签名证书与上一版本一致
- [ ] APK 中没有 `lib/*.so`，避免无关 ABI/16 KB 页问题

## 手机兼容

- [ ] Android 9：定位权限后能扫描经典蓝牙
- [ ] Android 12：请求“附近设备”权限，不强制定位
- [ ] Android 13–15：扫描、连接、重连、打印正常
- [ ] Android 16 / MagicOS 10：扫描、连接、打印正常
- [ ] 小米 HyperOS、荣耀 MagicOS、OPPO ColorOS、vivo OriginOS 各至少一台
- [ ] 大字体、显示缩放、深色模式下无按钮遮挡

## GP-M322 实打

- [ ] 使用 50 × 40 mm 标签纸，间隙默认 2 mm
- [ ] “冷藏 / 冷冻 / 常温”完整且不出右边界
- [ ] 日期固定两行：`yyyy-MM-dd` 和 `HH:mm`
- [ ] 连续打印 5 张，起始位置和走纸一致
- [ ] 冷藏、冷冻、常温各打印一张，勾选正确
- [ ] 长食材名和操作人不会越界
