# 开发说明

## 架构

- UI：单 Activity + Fragment，XML ViewBinding
- 数据：Room；首次启动从 UTF-8 JSON 导入，升级时优先读取旧版 `print.db`
- 打印：Canvas 按打印机点阵绘图 → 1-bit 位图 → TSPL `BITMAP` 指令 → 蓝牙 SPP
- 配置：SharedPreferences 保存标签尺寸和操作人

手机屏幕只显示预览。打印图始终按 203 DPI 生成，默认 400 × 320 dots，因此不会随手机分辨率、系统字体缩放或厂商 ROM 改变。

## 版本发布

1. 修改 `app/build.gradle` 的 `versionCode` 和 `versionName`。
2. 使用公司保管的同一 release keystore。
3. 运行 `gradlew clean testReleaseUnitTest lintRelease assembleRelease`。
4. 用 `apksigner verify --verbose --print-certs` 核对证书。
5. 在 Android 9、12、15、16 至少各安装一台，并用 GP-M322 实打。

## 增加打印机型号

不要按手机品牌分支打印代码。应新增打印机配置（DPI、纸宽、协议、方向），并保持 `LabelRenderer` 只关心点阵尺寸、协议编码器只关心字节输出。

## 数据迁移

Room schema 发生变化时增加数据库版本和 `Migration`，不要使用 `fallbackToDestructiveMigration()`。公司手机上的自定义模板属于用户数据，发布前必须覆盖安装测试。
